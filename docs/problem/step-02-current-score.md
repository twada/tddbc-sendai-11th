# モルックの得点記録

小さなテストから始めて、モルックの得点計算を段階的に育てていきましょう。

このお題は、[TDDBC Sendai 11th](https://tddbc.connpass.com/event/407078/)（2026-10-24）のために作成しました。

## モルック（Mölkky）とは

モルックは、複数のチームが得点を競い合うゲームです。各チームが順番に投てきを行い、得点を積み重ねていきます。

モルックでは、1〜12の番号（スキットル番号、skittle number）が付いた木製のピン「スキットル（skittle）」を使用します。各番号のスキットルは1本ずつあり、全部で12本です。

木製の棒「モルック（mölkky）」を投げてスキットルを倒すことを「投てき（throw）」と呼びます。

## STEP 01　投てきの点数を計算する

このお題では、まず1チームの投てきを扱います。1回の投てきで得られる点を「点数（points）」と呼びます。点数は、倒れたスキットルによって決まります。

### STEP 01-1：1本倒した場合

1回の投てきでスキットルを1本倒した場合、そのスキットル番号が点数になります。

例えば、5番のスキットルを倒した場合は5点、12番のスキットルを倒した場合は12点です。

```java
new 投てき(5).点数();  // 5
new 投てき(12).点数(); // 12
```

### STEP 01-2：2本以上倒した場合、1本も倒さなかった場合

1回の投てきでスキットルを2本以上倒した場合は、倒したスキットルの本数が点数になります。

1本も倒さなかった場合は0点です。

```java
new 投てき(5, 8).点数(); // 2
new 投てき().点数();     // 0
```

コードはJava風の呼び出し例です。日本語の識別子やクラス構成を指定するものではありません。

## STEP 02　現在の得点を求める

チームの点を「得点（score）」と呼びます。モルックでは、投てきを繰り返して得点を積み重ねていきます。得点は0点から始まります。

複数回の投てきの点数を合計し、現在の得点を求められるようにしてください。

例：1回も投てきしていないときは0点です。1回目に5本倒すと現在の得点は5点、2回目に11番を1本倒すと16点になります。
