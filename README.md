# tddbc-sendai-11th

限定された仕様のモルック(Mölkky)を題材にした TDD 演習用リポジトリ。

## 必要なもの

- Node 26

## セットアップ

```sh
npm install
```

## よく使うコマンド

```sh
npm test            # テスト実行
npm run test:watch  # 監視モード
npm run check       # 型検査 + lint + format チェック + テスト
```

構成と設計判断は [docs/architecture.md](docs/architecture.md) と [docs/adr/](docs/adr/) を参照。
